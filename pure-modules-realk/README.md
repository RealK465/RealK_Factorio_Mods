# Pure Modules

Pure modules are new tiers of dedicated modules that let you have a better bonus with fewer negative effects (no quality penalty, no speed penalty, reduced power penalty...)

They are incredibly powerful, so they require a dedicated high-tech beacon to work.

This mod only adds new features, no existing vanilla recipes are touched.

## Modules

A new top tier of modules, more powerful and with reduced penalties.

- **Speed** — faster than tier 3, without the quality hit.
- **Productivity** — more output than tier 3, without the speed hit.
- **Quality** — better quality than tier 3, with no drawback at all. (requires the Quality mod)

There's no Pure efficiency module — tier 3 already has no drawback left to remove. (maybe it will be reviewed, let's see)

## Pure Beacon

A dedicated high-tech beacon with the capacity to carry the power of the Pure modules.

It has a big range, and three of them on one machine transmit more than twelve ordinary
beacons. Three is the cap — a fourth adds nothing.

It pays for that in power, and it is the only beacon in the game that pollutes.

**There are mod settings for configuring which modules the beacon supports.**

## Compatibility

* Base Game
* Space Age and Quality are optional

No changes are made to existing recipes.

**Safe to add to an existing save.**

  beacons tied to other planets, if the right mod comes along.
- **More languages** — the mod is English only for now.
