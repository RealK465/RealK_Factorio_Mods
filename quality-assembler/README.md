# Quality Assembler

**An assembling machine with quality built right in.**

A 3x3 assembler that crafts 60% faster than an assembling machine 3. Everything it makes has a
12% chance of coming out at a higher quality, with no modules fitted. It has five module slots,
takes fluids like any assembler, and draws more power.

It swaps straight in over an assembling machine 3, so you can upgrade a line without rebuilding
it.

With Space Age it unlocks after Aquilo, alongside the other endgame machines. Without Space Age
it unlocks after the rocket. Either way it needs the Quality mod.
