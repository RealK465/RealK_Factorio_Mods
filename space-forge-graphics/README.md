# Space Forge Graphics

Art for [Space Forge](../space-forge/) — sprites, icons and sounds, and nothing else. There
is no Lua in this mod: it adds no items, no recipes and no entities, and enabling it on its
own changes nothing in game.

Install **Space Forge**, which requires this mod and will pull it in.

## Why it is separate

The art is the heavy half of an overhaul and the half that changes least. Splitting it out
means a balance patch to Space Forge is a few kilobytes rather than a full re-download.
