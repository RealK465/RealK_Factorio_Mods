# Robot World Continued (RealK)

**Tune your robots and roboports. Optionally start the game with robots.**

A Factorio 2.1 port of Robot World Continued. Everything is set in Settings > Mod settings > Startup.

## What you can change

- **Robots:** speed, cargo size, battery, energy use, health and stack size.
- **Roboports:** logistic area, construction area, charging speed and idle power.
- **Inserters:** speed.

## Start with robots

- **Early robots:** build robots and roboports from the start, with cheap recipes.
- **Quick start kit:** start with buildings, steam power, labs, robots and roboports.
- **Power armor:** start in power armor MK2 with personal roboports.

## Compatibility

Works with or without Space Age, and with Krastorio 2. Can't be used together with Robot World or Robot World Continued.
